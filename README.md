## The pitch

> We train crows to collect cigarette butts from city parks and charge the city per kilo, because the birds work for peanuts - literally.

135 characters, one sentence. Ridiculous at first glance — a workforce of
crows — and real by the second: cities already pay crews to pick up
cigarette butts, the payer and the price (per kilo) are named, and the
turn from laughing to nodding is the last two words.

## How it works

`main.py` (Python 3.13 standard library only, no network) writes the pitch
to `/output/entry.txt`:

```sh
python3 main.py
```

It self-checks the competition gate first: 1–200 characters, a single line,
not only whitespace. The output is deterministic — every run writes the
exact same bytes.
